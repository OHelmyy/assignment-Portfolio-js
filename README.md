# Interactive Portfolio - Vanilla JavaScript

A responsive personal portfolio built with semantic HTML, Tailwind CSS, and pure **Vanilla JavaScript** (no external UI libraries or Bootstrap).

##  Features Implemented
-  **Scroll Spy**: Automatically updates active navbar navigation links as you scroll.
-  **Dark / Light Mode**: Seamless theme toggle with state saved in `localStorage`.
-  **Portfolio Filter Tabs**: Category filtering for projects using pure DOM manipulation.
-  **Testimonials Carousel**: Custom RTL slider with responsive card count, navigation controls, and indicators.
-  **Settings Sidebar (Customizer)**: Real-time customization of primary theme colors and font families with persistence.
-  **Scroll to Top**: Smooth scroll button that reveals itself on scroll.
